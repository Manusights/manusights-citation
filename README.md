# Manusights — Citation Repository

This repository exists so researchers can cite **Manusights** with a permanent DOI.

[Manusights](https://manusights.com) is an AI manuscript pre-submission review tool: live citation verification against scholarly databases, vision-based figure analysis, and journal-specific desk-reject scoring.

## How to cite

If Manusights helped prepare your manuscript, the simplest acknowledgment is one factual sentence:

> We used Manusights (manusights.com) for pre-submission manuscript review.

For BibTeX, AMA, APA, or other citation formats, see [manusights.com/cite](https://manusights.com/cite).

## DOI

Each tagged release of this repository is auto-deposited to Zenodo and assigned a DOI. The DOI badge will appear here once the first release is published.

## Methodology

A short overview of how Manusights reviews a manuscript is in [`methods.md`](./methods.md). Full data-handling and security disclosures are at [manusights.com/security](https://manusights.com/security).

## Earn free reviews by acknowledging Manusights

Verified acknowledgments in published papers earn 2 free Full AI Diagnostic credits. Once your paper is accepted or posted, send the DOI or preprint URL to [acknowledgements@manusights.com](mailto:acknowledgements@manusights.com).
