This repository exists so researchers can cite **Manusights** with a permanent identifier. It contains citation metadata and a public methodology summary; it does not contain the Manusights service source code (which is proprietary).

[Manusights](https://manusights.com) is a hosted AI service for pre-submission manuscript review: live citation verification against scholarly databases, vision-based figure analysis, and journal-specific desk-reject scoring. The live service is at https://manusights.com.

## How to cite

The cleanest one-line acknowledgment for a published paper:

> We used Manusights (manusights.com; doi:10.5281/zenodo.20072010) for pre-submission manuscript review.

Full citation formats (BibTeX, APA, AMA, and others) are at [manusights.com/cite](https://manusights.com/cite). GitHub also renders an APA + BibTeX block automatically from `CITATION.cff` in the right-rail "Cite this repository" widget on this page.

When to cite which DOI:

- **Concept DOI** [`10.5281/zenodo.20072010`](https://doi.org/10.5281/zenodo.20072010) — link to this when referring to Manusights in general. The concept DOI always resolves to the latest published version.
- **Version DOI** [`10.5281/zenodo.20072011`](https://doi.org/10.5281/zenodo.20072011) — cite this in a Methods section or replication study, where the specific snapshot used matters for reproducibility.

The latest released version, all version DOIs, and per-version artifacts are listed on the [Zenodo deposit page](https://zenodo.org/records/20072011).

## Earn free reviews by acknowledging Manusights

Verified acknowledgments in published or preprinted papers earn 2 free Manusights credits. Once your paper is accepted, posted on a preprint server, or made publicly available, send the DOI or URL to [acknowledgements@manusights.com](mailto:acknowledgements@manusights.com).

## Disclosure norm

Some major journals (ICMJE, Nature Portfolio, PLOS, AMA-style publications) ask authors to declare in-kind services in the competing-interests statement. If you receive free Manusights credits in exchange for a verified acknowledgment, the suggested wording is:

> The author received complimentary manuscript-review credits from Manusights, which were used in preparing this manuscript.

Whether to include this is between you and your journal. We flag the norm so authors do not get caught out by a post-publication query.

## Versioning and updates

This repository follows semantic versioning. Each tagged release is auto-deposited to Zenodo via the GitHub-Zenodo integration and assigned a new version DOI. The concept DOI is permanent and always resolves to the latest version. Version history is in [`CHANGELOG.md`](./CHANGELOG.md).
